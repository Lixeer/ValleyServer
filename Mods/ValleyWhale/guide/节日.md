## 节日专题（日期和入场时间来自游戏数据，玩法来自 Stardew Valley Wiki）

### 通用流程
- 节日当天镇上的商店和住宅全天关门（除了不需要入场的节日），所以前一天把要买的买好。
- 入场时间内用 **festival enter** 走到节日地点入场，节日里**时间不走**、普通工具不能用。
- 入场后 **festival greet**：挨个和村民说话，节日上说话也加好感（每人每天一次）。
- 然后 **festival start**：找刘易斯，回答“准备好了”开始主活动；主活动结束后游戏把你送回农场（一般是晚上 10 点，月光水母之舞和万灵节是半夜 12 点），之后收拾一下就 sleep。
- 不想参加主活动就 festival leave。节日当天地里的作物照样要浇（早上先浇完再去）。

### 联机时的节日（你是农场工人时）
- **入场**：所有玩家都走到节日地点才开始，先到的要等后到的。到点就去，别让人等。
- **主活动只有主机能开始**（冬日星盛宴、万灵节除外）：只有主机和刘易斯说话时才会问“准备好了吗”，主机答应后所有人立刻开始，不会等你。
- **你要做的**：入场后 festival greet，再 festival start。它会先做开始前要做的事（花舞节邀舞伴、夏威夷宴会放汤、冬日星盛宴送礼物），说一声“我准备好了”，然后等主机开始，开始后自动过对白、捡彩蛋或钓鱼。这些准备要赶在主机开始之前，所以一入场就做。
- **有人说话时**：festival start 会先停下来让你回话，回完再 festival start 接着等。
- **主活动开始了就别走**：状态里出现【节日主活动已经开始了】就马上 festival start 加入。找彩蛋和冰钓比赛是各算各的，你也能赢奖品。对白要一句句过，找完彩蛋、钓完鱼还要等所有人，你不过完，主机也动不了。
- **提前离开**：主活动开始之前才能 festival leave，而且要所有玩家都同意。
- **花舞节（春 24）**：舞伴要在主机开始之前邀请好，开始后就来不及了。其他玩家也可能邀请你，会弹出问题，用 dialogue 传 choice=0 答应。
- **夏威夷宴会（夏 11）**：每个玩家都要往汤里放东西，有人没放，州长就只给普通评价，放得再好也没用。汤要在主机开始之前放好。跟主机说一声让对方也放。
- **月光水母（夏 28）**：没有要准备的，开始后看表演。
- **冰雪节（冬 8）**：和复活节一样，开始后各钓各的。开始前和结束后都要等所有人。
- **冬日星盛宴（冬 25）**：**没有要主机开始的主活动**，每个人给自己抽到的村民送完礼物，就各自播放交换的剧情。festival start 会替你送，不用等主机。送完想走就 festival leave，要所有玩家都同意。
- **展览会（秋 16）**：展示柜大家共用，先用 say 问主机要不要你来摆，同意了再 festival grange。评分只有主机能开始，评完再 festival start 找刘易斯领奖。
- **万灵节（秋 27）**：没有主活动，festival start 去迷宫开宝箱，各开各的。

### 不用入场的节日（时间照常走，商店照常开）
- **沙漠节**（春 15-17，沙漠 10:00-次日 2:00）：巴士修好以后才去得了沙漠，有商店和小游戏。
- **鳟鱼大赛**（夏 20-21，森林的河）：在森林河里钓**虹鳟鱼**，有机会得到金标签，在大赛摊位换奖品。用 fish 去森林河边钓就行。
- **鱿鱼节**（冬 12-13，海边）：在海边钓**鱿鱼**，12 日钓 8 条、13 日钓 10 条能拿到全部奖励。
- **夜市**（冬 15-17，海边 17:00-次日 2:00）：商店、美人鱼表演、深海潜艇钓鱼。
